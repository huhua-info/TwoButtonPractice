# 雙按鈕計數器 — 功能需求

## 專案目標

建立一個 Windows 桌面練習程式，讓使用者學習透過需求文件驅動 AI 開發、測試與修正。

- 名稱：雙按鈕計數器（TwoButtonPractice）。
- 技術：C#、.NET 10、Avalonia、MVVM。
- UI：單一視窗，內容區恰好兩個按鈕。
- 預設按鈕功能：增加計數、重設計數。
- 計數僅存於記憶體，關閉程式後不保存。

本文件為後續開發規格，取代原有範例需求；目前僅完成文件，尚未實作程式。增加與重設為本練習採用的預設行為。

## 畫面需求

視窗標題為「雙按鈕計數器」，初始大小約 480 × 320，最小大小為 360 × 240（Avalonia 邏輯單位）。內容置中並保留適當間距。

```text
┌──────────────────────────────────┐
│ 雙按鈕計數器                     │
│                                  │
│          按鈕操作練習            │
│                                  │
│          目前次數：0             │
│                                  │
│      [增加次數]    [重設]        │
│                                  │
│          請按下按鈕開始          │
└──────────────────────────────────┘
```

- 使用繁體中文顯示文字。
- 內容區只有「增加次數」與「重設」兩個按鈕；系統標題列控制不計入。
- 狀態訊息顯示於視窗內，不另開對話框。
- 不增加選單、額外頁面或功能按鈕。

## F002：「增加次數」按鈕

狀態：待實作。

### 功能規則

- 每次啟動按鈕，計數增加 1，畫面立即更新。
- 狀態訊息變成「已增加 1 次」。
- 每次有效操作只增加一次，連續操作不重複或遺失計數。
- 為明確定義邊界，計數範圍為 0～999。
- 到達 999 時顯示「已達上限 999 次」，停用增加按鈕，數值不可溢位或超出上限。
- 重設後恢復增加按鈕。

### 驗收條件

- 從 0 按一次變成 1，按五次變成 5。
- 從 0 連續按十次變成 10，畫面保持回應。
- 從 998 增加一次得到 999，上限訊息正確，增加按鈕停用。
- 上限狀態下，計數不會變成負數或超過 999。

## F003：「重設」按鈕

狀態：待實作。

### 功能規則

- 按下後計數變成 0，訊息為「已重設為 0」。
- 重設按鈕始終可用，計數已為 0 時仍可操作。
- 重設後增加按鈕可用，下一次增加得到 1。

### 驗收條件

- 從 5 重設得到 0，訊息正確。
- 從 0 重設仍為 0，不出現錯誤。
- 從 999 重設得到 0，增加按鈕恢復可用。
- 重設後再增加一次得到 1。

## F004：鍵盤操作與程式生命週期

| 案例 | 操作 | 預期結果 |
| --- | --- | --- |
